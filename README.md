# AI Systems Portfolio — Monash Projects

This repository contains a collection of AI systems built as part of my Master’s in Artificial Intelligence at Monash University.

Unlike typical coursework, these projects focus on building systems from first principles — implementing algorithms, models, and architectures without relying on high-level abstractions.

---

## Featured Systems

### Multi-Agent Reinforcement Learning (DQN)
- Built multi-agent system using Deep Q-Networks
- Implemented experience replay and target networks
- Designed curriculum learning strategy
- Enabled coordinated behaviour across agents

---

### Hybrid AI Agent (Planning + Probabilistic Reasoning)
- Combined A* search, particle filtering, and symbolic reasoning
- Designed risk-aware decision-making under uncertainty
- Applied to competitive multi-agent environment

---

### Machine Learning from Scratch
- Implemented KNN with KDTree optimisation
- Built full cross-validation pipeline
- Applied bias-variance analysis and model selection

---

### Deep Learning from Scratch
- Built neural networks using PyTorch tensors only
- Implemented SGD, Momentum, and AdaGrad
- Trained model on MNIST dataset
