## Overview

A design-first unit covering the full human-centred design (HCD) process — from user research and task analysis through to iterative prototyping and formal usability evaluation. The unit treats UI design not as aesthetic choice but as a structured, evidence-based engineering discipline, with every decision grounded in user needs, cognitive principles, and measurable usability criteria. Particularly relevant for AI practitioners building interfaces where transparency, error recovery, and trust are critical.

---

## What I Worked On

- Conducted user research to identify target user groups, goals, and pain points for a defined interaction problem
- Produced low-fidelity wireframes to rapidly explore layout, navigation structure, and information hierarchy
- Applied Nielsen's 10 usability heuristics to evaluate an existing interface and produced a structured heuristic evaluation report with severity ratings
- Developed a high-fidelity interactive prototype iterating on findings from early-stage feedback
- Designed and conducted a usability test session, including task scenario scripting, think-aloud protocol facilitation, and post-task analysis
- Documented accessibility considerations against WCAG standards and recommended design improvements

---

## Methods and Approaches

- **User-Centred Design (UCD)** process: research → ideation → prototype → evaluate → iterate
- **Heuristic evaluation** using Nielsen's 10 heuristics with structured severity scoring
- **Task analysis** to decompose user goals into interaction sequences and identify failure points
- **Think-aloud usability testing** protocol for capturing real-time user reasoning and confusion signals
- **Wireframing and prototyping** progressing from lo-fi sketches to hi-fi interactive mockups
- **WCAG accessibility guidelines** applied to contrast ratios, labelling, and keyboard navigability

## Key Insights

- Heuristic evaluation and usability testing surface different issue types — expert review catches structural violations; user testing reveals actual task-completion failures that experts often miss
- Mental model mismatches between designers and users are the most common source of usability failures — early task analysis is the most cost-effective way to catch them
- Designing AI-facing interfaces demands particular attention to feedback, explainability, and graceful error handling: users need to understand system state and recover from unexpected outputs

---

## Relevance to Industry

- **AI Product Design:** Critical for building AI-powered tools where users must interpret model outputs, calibrate trust, and recover from errors
- **UX Research & Design:** Direct application of industry-standard evaluation methods (heuristics, usability testing, WCAG)
- **Product Management:** Provides a principled framework for prioritising UI improvements based on measurable impact on user task completion
